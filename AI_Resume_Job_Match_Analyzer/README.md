# 🤖 AI Resume–Job Match Analyzer

A Python-based AI application that analyzes a resume against a job description, identifies technical skill gaps, and generates personalized career recommendations using the OpenAI API.

This project was built as part of my journey toward becoming an **AI/ML Engineer**, with a focus on understanding how different components of a practical AI application work together.

---

## 🎯 Problem

Students and job seekers often apply for roles without clearly understanding:

- Which required skills are already present in their resume
- Which technical skills are missing
- What they should learn next
- What projects could help strengthen their profile
- What interview questions they should prepare for

Instead of manually comparing a resume with every job description, this application performs an initial analysis automatically.

---

## 💡 Solution

The **AI Resume–Job Match Analyzer** allows a user to:

1. Upload a resume in PDF format
2. Paste a job description
3. Extract technical skills from both
4. Calculate the technical skill overlap
5. Identify matched and missing skills
6. Generate personalized feedback using OpenAI
7. Suggest actionable next steps
8. Recommend a relevant project
9. Generate potential interview questions

---

## ✨ Features

### 📄 Resume PDF Processing
Extracts readable text directly from an uploaded PDF resume.

### 🔍 Technical Skill Detection
Detects predefined technical skills from both the resume and job description.

### 📊 Deterministic Match Score
Calculates the percentage of job-description skills found in the resume.

### ✅ Matched Skills
Shows technical skills present in both the resume and job description.

### 🎯 Missing Skills
Identifies skills requested by the job description but not detected in the resume.

### 🧠 AI-Powered Feedback
Uses the OpenAI API to provide:

- Overall analysis
- Resume strengths
- Important gaps
- Recommended next steps
- Suggested project ideas
- Relevant interview questions

### 🖥️ Interactive Interface
Built using Streamlit for a simple and interactive web experience.

## 🧠 Why the Match Score Is Not Generated by AI

One important design decision in this project was to separate **deterministic application logic** from **generative AI**.

The application does **not** ask the LLM:

> "How much does this resume match this job?"

Instead, Python detects the technical skills in the resume and job description and calculates the overlap.

For example:

```text
Job Description Skills:
Python
SQL
Pandas
Machine Learning
Scikit-learn

Resume Skills:
Python
SQL
Pandas

Matched Skills = 3
Required Skills = 5

Technical Skill Match = 3 / 5 × 100 = 60%
```

The calculated information is then passed to the OpenAI API.

The AI model is used for tasks where language understanding is more useful, such as explaining gaps, recommending next steps, suggesting projects, and generating interview questions.

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Move into the project directory:

```bash
cd ai-resume-job-matcher
```

### 2. Create a Virtual Environment

Mac/Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

```bash
python -m venv .venv
.venv\Scripts\activate
```


## ⚠️ Current Limitations

This is an educational V1 project and has several limitations.

### Rule-Based Skill Detection

The current version detects skills using a predefined skill list.

This means a technical skill that is not included in the list may not be detected.

### Skill Presence ≠ Skill Proficiency

If a skill appears in a resume, the application can detect its presence, but it cannot determine how proficient the candidate actually is.

### Match Score Is Limited

The technical match percentage represents detected skill overlap only.

It does not consider all factors employers may evaluate, such as:

- Experience
- Education
- Project quality
- Domain knowledge
- Communication
- Problem-solving ability
- Cultural/team fit

Therefore, the score should **not be interpreted as an employer's actual hiring score or probability of selection**.
